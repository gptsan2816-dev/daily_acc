토큰은 페이지 이동을 위해 현재 탭의 세션에 보관됩니다. 연결 해제 시 삭제되며, 주소나 가계부 파일에 포함되지 않습니다. 공용 기기에서는 사용 후 연결을 해제하세요.

처음 연결하나요?
  1. GitHub에서 비공개 저장소를 만들고 README를 추가하세요.
  2. 접근 토큰 발급에서 해당 저장소만 선택하고 Contents에 Read and write 권한을 주세요.

새 파일은 빈 가계부로 생성합니다. 기존 파일은 덮어쓰지 않습니다.
