GitHub 연결

토큰과 가계부는 브라우저에 영구 저장하지 않습니다. 페이지를 닫기 전에 GitHub에 저장하거나 백업하세요.

처음 연결하시나요?
  1. 비공개 저장소에 ledger.json을 만드세요.
    {"version":1,"currency":"KRW",
"transactions":[]}
  2. GitHub에서 토큰 발급: Resource owner는 저장소 소유자, Repository access는 해당 저장소만 선택하세요.
  3. Repository permissions의 Contents를 Read and write로 설정하고 만료일을 지정하세요.
  4. 위 정보를 입력한 뒤 불러오기를 누르세요. 토큰을 코드나 데이터 파일에 넣지 마세요.

공개 저장소에는 연결하지 않습니다. 다른 기기의 변경이 있으면 저장을 중단합니다. 현재 내역을 백업한 후 최신 데이터를 불러와 필요한 내용을 다시 입력하세요.

거래 내역을 삭제해도 GitHub 커밋 기록에는 이전 내용이 남을 수 있습니다.

GitHub Pages에 올리는 방법
  1. 공개 웹사이트 저장소에 이 파일을 index.html 이름으로 업로드하세요.
  2. Settings → Pages → Deploy from a branch를 선택하세요.
  3. main / (root)를 선택하고 Save를 누르세요.
  4. 표시된 사이트 주소에 접속해 비공개 데이터 저장소를 연결하세요.
